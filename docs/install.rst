Instalação
==========

- Criar ambiente conda

.. code-block:: console

  conda create -n cptec python=3.10

  conda activate cptec


**Via pip**
  
.. code-block:: console

  pip install cptec-monan


**Help**
  
.. code-block:: console

  python3 -c "import monanmodel.CPTEC_MONAN as MON; help(MON)"
