### CPTEC-MONAN

É um pacote in Python para a distribuição de dados brutos de previsão do MONAN - CPTEC/INPE. site [https://previsaonumerica.cptec.inpe.br/monan/prec/ams/](https://previsaonumerica.cptec.inpe.br/monan/prec/ams/).


support Python >= 3.10.
